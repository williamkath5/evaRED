## 🧭 Estructura del sitio (SPA)

1. **Inicio** — Portada institucional y resumen ejecutivo.
2. **Modelos de Evaluación y RED** — Panorama de 6 modelos (LORI, COdA, UNE 71362:2020, FURPS, McCall, Boehm).
   - 2.1 **Seleccionando Modelos** — Justificación, pros/contras y guión del video de sustentación.
   - 2.2 **Recursos Educativos Digitales** — Fichas técnicas de W3Schools y Codecademy.
3. **Rediseño** — Modelo híbrido **ECO-RED Normalista** (4 dimensiones ponderadas).
4. **Aplicación de Modelos** — Matrices LORI, COdA y UNE con resultados reales.
5. **Referencias Bibliográficas** — Normas APA 7.ª ed.

---

## 🛠️ Tecnologías

- **HTML5** semántico con atributos ARIA.
- **CSS3** moderno: variables CSS, Flexbox, Grid, glassmorphism, diseño 100% responsivo.
- **JavaScript vanilla** modular: navegación SPA, tabs, acordeones, barras animadas (IntersectionObserver).
- **Express.js** como servidor estático ligero para despliegue.

---

## 🚀 Ejecución local

```bash
npm install
npm start
# Abrir http://localhost:3000
```

## ☁️ Despliegue en Railway

1. Conecta este repositorio de GitHub a Railway.
2. Railway detecta `package.json` y ejecuta `npm start` automáticamente.
3. El servidor Express escucha en `process.env.PORT`.

> También es desplegable como sitio estático (GitHub Pages) sirviendo `index.html`.
